# Settled collaboration items — archive

The closed half of `collab.md`, so the open file stays short enough to read in one sitting. **Item
numbers run as one sequence across both files**, never restarting: two people taking the same number
is the collision union merge cannot show you. Union-merged on the same terms, and **nothing here is
edited after it lands** — a settled item that turns out wrong is a new item in `collab.md`. Only a
skill that sweeps moves an item here, because moving it by hand skips the sweep's audits; an item
settled between sweeps gets its answer appended, is marked settled, and stays where it is.

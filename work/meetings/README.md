# Meetings

One file per joint working session, `<YYYY-MM-DD>.md`, written by `/make-agenda` and stamped
`Status: executed` by `/end-meeting` — exactly two states, because only those two skills write to
it, at the two ends. **No owner in the path**, for the reason `work/archive/` has none: a meeting
belongs to everyone in it. **Not union-merged, deliberately** — one file per date means two people
cannot append to the same one, which is the condition union merge exists for.

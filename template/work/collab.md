# Collaboration agenda

<!-- DELETE THIS FILE IF YOU WORK ALONE. It only earns its place once a second person clones the
     repo and runs /start and /save on their own machine. -->

Shared running agenda for checkpoints between the people who share this repo. Everyone reads and
writes it; it is not addressed at any one person — a file called "to discuss with <name>" reads as
self-referential on that person's machine, which is the mistake this file exists to avoid.

An item belongs here when a decision on one side **conflicts with or overrides** work on the other.
Not every disagreement — the ones where proceeding silently would waste someone's work.

Add items as they come up; mark them **Agreed** with a date once settled, and don't delete — the
trail is the point.

Stamp every item with who raised it: `*Raised YYYY-MM-DD — <author>.*` If the repo root
`.gitattributes` sets `merge=union` on `.claude/work/*.md` (recommended — see `CLAUDE.md`, "More
than one person uses this `.claude/`"), concurrent appends merge cleanly but a genuine collision
merges *silently*. The stamp is what makes an accidental duplicate visible.

Persistent: survives `/done`, because coordination outlives any one task.

---

## Open

### 1. <the decision, stated as what it changes for them>
What you did, what it overrides, and what you want from them — **Confirm**, **Decide**, or just
noting it. Say which; an item with no ask sits open forever.

Link the reasoning rather than repeating it: `decisions.md`, <YYYY-MM-DD>.
*Raised <YYYY-MM-DD> — <author>.*

## Agreed

### <the item> — accepted (<YYYY-MM-DD>)
What was settled, and any consequence that outlived it — a doc now stale, a follow-up owed.
Agreed items are never deleted; the trail is what stops the same argument recurring.
